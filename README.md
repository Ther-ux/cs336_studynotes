# CS336 Study Notes

Stanford CS336「Language Modeling from Scratch」的个人学习笔记与实践记录。

本仓库用于整理课程中的核心概念、推导、实现思路和实验观察，按照从语言模型基础到训练与后训练的脉络持续补充。课程内容和作业安排请以 [Stanford CS336 官方网站](https://cs336.stanford.edu/) 为准。

## 学习主题

- **基础**：分词、PyTorch 与计算资源估算、Transformer 架构、注意力机制和混合专家模型（MoE）
- **系统**：GPU/TPU、Triton 与高效算子、并行训练和推理
- **训练与评估**：缩放规律、模型训练、推理、评估方法
- **数据**：预训练数据来源、过滤、去重、混合与合成数据
- **后训练**：监督微调（SFT）、RLHF、RLVR 和多模态模型
